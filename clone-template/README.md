# clone-template

چند VM (پیش‌فرض: ۷ تا) از یک تمپلیت موجود در Proxmox می‌سازد. برای هر VM **اسم، ID، کارت شبکه و IP** را در فایل تنظیمات (`terraform.tfvars`) تعیین می‌کنید. بقیه‌ی تنظیمات دقیقاً از تمپلیت کپی می‌شوند: BIOS و EFI Disk، دیسک‌ها، کنترلر SCSI، CPU و حافظه. خود تمپلیت هم دست نمی‌خورد.

این پوشه مستقل است و به بقیه‌ی ریپو ربطی ندارد.

## تعریف VM ها

در `terraform.tfvars`، داخل `vms`. کلید هر مورد اسم VM است:

```hcl
vms = {
  "k8s-master-1" = {
    vm_id = 301
    networks = {
      net0 = { bridge = "vmbr1", model = "vmxnet3", ip = "192.168.1.61/24", gateway = "192.168.1.1" }
    }
  }
  # ... بقیه‌ی VM ها
}
```

| فیلد | اجباری | توضیح |
|------|--------|-------|
| `vm_id` | بله | ID ماشین؛ برای هر VM باید فرق کند |
| `node` | نه | نود Proxmox؛ پیش‌فرض `node_name` |
| `networks` | نه | کارت‌های شبکه بر اساس اسلات (`net0`، `net1`، ...). اسلاتی که نیاورید همان تنظیمات تمپلیت را نگه می‌دارد |
| `dns_servers`، `dns_domain` | نه | DNS مخصوص همین VM؛ پیش‌فرض مقدار سراسری |

فیلدهای هر کارت شبکه:

| فیلد | توضیح |
|------|-------|
| `bridge` | بریج، مثلاً `vmbr1` (اجباری) |
| `model` | `vmxnet3` (مثل تمپلیت ۱۰۴)، `virtio` یا `e1000` |
| `vlan_id` | تگ VLAN |
| `mac_address` | MAC ثابت؛ اگر نیاورید تصادفی ساخته می‌شود |
| `firewall`، `mtu` | اختیاری |
| `ip` | `"192.168.1.61/24"` یا `"dhcp"`؛ اگر نیاورید IP تمپلیت می‌ماند |
| `gateway` | گیت‌وی |

برای اضافه یا کم کردن VM، فقط یک مورد به `vms` اضافه یا از آن حذف کنید.

## درباره‌ی IP

ریسورس `proxmox_cloned_vm` خودش Cloud-Init را مدیریت نمی‌کند، برای همین Terraform بعد از کلون IP و DNS را با یک دستور `curl` از طریق API روی هر VM جدید می‌نویسد (`curl` در ویندوز ۱۰ به بعد، لینوکس و مک موجود است). VM ها هنوز خاموش‌اند، پس در اولین بوت اعمال می‌شوند.
برای اینکه IP واقعاً روی سیستم‌عامل بنشیند، باید داخل تمپلیت پکیج `cloud-init` نصب باشد.

## اجرا

```bash
cd clone-template
cp terraform.tfvars.example terraform.tfvars   # آدرس و توکن API، اسم‌ها، IP ها و شبکه را بنویسید
terraform init
terraform apply
```

VM ها ساخته می‌شوند ولی **روشن نمی‌شوند**. از وب Proxmox روی `Start` بزنید.

برای تغییر بعدی: `terraform.tfvars` را عوض کنید و دوباره `terraform apply` بزنید. تغییر کارت شبکه مستقیم اعمال می‌شود. ولی Cloud-Init تغییر IP را معمولاً فقط در بوت بعدی اعمال می‌کند، پس بعد از `apply` باید VM را ری‌استارت کنید. **تغییر اسم یا `vm_id` یک VM آن را پاک می‌کند و از نو می‌سازد.**

## حذف

```bash
terraform destroy
```

## تنظیمات سراسری

| متغیر | پیش‌فرض | توضیح |
|-------|---------|-------|
| `template_id` | `104` | تمپلیت مبدأ |
| `node_name` | `hvir111d` | نود پیش‌فرض VM ها |
| `template_node` | خالی | نود تمپلیت، اگر با نود VM فرق دارد |
| `datastore` | `iscsi-netapp` | محل دیسک‌های کلون؛ خالی = همان datastore تمپلیت |
| `dns_servers` | خالی | DNS همه‌ی VM ها؛ خالی = همان تمپلیت |
| `dns_domain` | خالی | Search domain همه‌ی VM ها |

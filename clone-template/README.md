# clone-template

چند VM (پیش‌فرض: ۷ تا) از یک تمپلیت موجود در Proxmox می‌سازد. برای هر VM **اسم، ID، اندازه‌ی دیسک، کارت شبکه و IP** را در فایل تنظیمات (`terraform.tfvars`) تعیین می‌کنید. بقیه‌ی تنظیمات دقیقاً از تمپلیت کپی می‌شوند: BIOS و EFI Disk، کنترلر SCSI، CPU و حافظه. خود تمپلیت هم دست نمی‌خورد.

این پوشه مستقل است و به بقیه‌ی ریپو ربطی ندارد.

## تنظیمات سراسری شبکه

مقادیری که برای همه‌ی VM ها یکی است فقط یک بار نوشته می‌شوند. با عوض کردن هر کدام، همه‌ی VM ها عوض می‌شوند:

```hcl
network_bridge = "vmbr1"
network_model  = "vmxnet3"
gateway        = "192.168.1.1"
ip_prefix      = 24          # به IP هایی که /prefix ندارند اضافه می‌شود
# vlan_id      = 20
dns_servers    = ["192.168.1.1", "8.8.8.8"]
disk_gb        = 50
```

## تعریف VM ها

`vms` یک آرایه است؛ هر خط یک VM:

```hcl
vms = [
  { name = "k8s-jumpbox",  vm_id = 300, ip = "192.168.1.60" },
  { name = "k8s-master-1", vm_id = 301, ip = "192.168.1.61" },
  { name = "k8s-worker-1", vm_id = 311, ip = "192.168.1.71", disk_gb = 100 },
]
```

- `name` و `vm_id` اجباری‌اند و باید یکتا باشند.
- `ip` برای کارت اول (`net0`): `"192.168.1.61"` (با `ip_prefix`)، `"192.168.1.61/24"` یا `"dhcp"`. اگر نیاورید IP تمپلیت می‌ماند.
- برای اضافه یا حذف VM فقط یک خط اضافه یا حذف کنید.

هر VM می‌تواند هر کدام از این‌ها را **فقط برای خودش** عوض کند؛ اگر نیاورد مقدار سراسری استفاده می‌شود:

| فیلد | توضیح |
|------|-------|
| `disk_gb` | اندازه‌ی دیسک (کمتر از دیسک تمپلیت، ۵۰، نمی‌شود) |
| `node` | نود Proxmox |
| `bridge`، `model`، `vlan_id`، `gateway` | تنظیمات کارت اول |
| `mac_address`، `firewall`، `mtu` | تنظیمات کارت اول (MAC پیش‌فرض تصادفی است) |
| `dns_servers`، `dns_domain` | DNS |
| `extra_networks` | کارت‌های اضافه: `net1`، `net2`، ... |

مثال:

```hcl
  { name = "other-net", vm_id = 320, ip = "10.20.0.5", bridge = "vmbr0", vlan_id = 20, gateway = "10.20.0.1" },
  { name = "two-cards", vm_id = 321, ip = "192.168.1.80",
    extra_networks = { net1 = { bridge = "vmbr0", vlan_id = 30, ip = "10.30.0.80/24" } } },
```

## درباره‌ی IP

ریسورس `proxmox_cloned_vm` خودش Cloud-Init را مدیریت نمی‌کند، برای همین Terraform بعد از کلون IP و DNS را با `curl` از طریق API روی هر VM جدید می‌نویسد (`curl` در ویندوز ۱۰ به بعد، لینوکس و مک موجود است). تنظیمات `curl` در فایل‌هایی داخل `.terraform/curl/` نوشته می‌شود تا روی PowerShell/cmd ویندوز هم درست کار کند؛ این فایل‌ها توکن API را دارند و در گیت ذخیره نمی‌شوند. VM ها تا اینجا خاموش‌اند؛ بعد از نوشتن IP روشن می‌شوند (`start_vms`)، پس IP در اولین بوت اعمال می‌شود.
برای اینکه IP واقعاً روی سیستم‌عامل بنشیند، باید داخل تمپلیت پکیج `cloud-init` نصب باشد؛ مراحل ساختن چنین تمپلیتی در [`TEMPLATE-CLOUD-INIT.md`](TEMPLATE-CLOUD-INIT.md) آمده است.

## اجرا

```bash
cd clone-template
cp terraform.tfvars.example terraform.tfvars   # آدرس و توکن API، اسم‌ها، IP ها و شبکه را بنویسید
terraform init
terraform apply
```

VM ها ساخته، تنظیم و **روشن** می‌شوند. اگر نمی‌خواهید خودکار روشن شوند، `start_vms = false` بگذارید.

برای تغییر بعدی: `terraform.tfvars` را عوض کنید و دوباره `terraform apply` بزنید. تغییر کارت شبکه مستقیم اعمال می‌شود. دیسک را می‌شود بزرگ‌تر کرد (نه کوچک‌تر)؛ بعد از آن پارتیشن داخل سیستم‌عامل را هم باید بزرگ کنید (`growpart` و `xfs_growfs`). ولی Cloud-Init تغییر IP را معمولاً فقط در بوت بعدی اعمال می‌کند، پس بعد از `apply` باید VM را ری‌استارت کنید. **تغییر اسم یا `vm_id` یک VM آن را پاک می‌کند و از نو می‌سازد.** ترتیب خط‌ها در آرایه مهم نیست.

## حذف

```bash
terraform destroy
```

## تنظیمات سراسری

| متغیر | پیش‌فرض | توضیح |
|-------|---------|-------|
| `template_id` | `104` | تمپلیت مبدأ |
| `node_name` | `hvir111d` | نود پیش‌فرض VM ها |
| `template_node` | خالی | نود تمپلیت، اگر با نود VM فرق دارد |
| `datastore` | `iscsi-netapp` | محل دیسک‌های کلون؛ خالی = همان datastore تمپلیت |
| `disk_gb` | `50` | اندازه‌ی پیش‌فرض دیسک VM ها |
| `template_disk_gb` | `50` | اندازه‌ی دیسک تمپلیت (حداقل مجاز) |
| `disk_interface` | `scsi0` | اسلات دیسک تمپلیت |
| `start_vms` | `true` | روشن کردن VM ها بعد از تنظیم |
| `network_bridge` | `vmbr1` | بریج پیش‌فرض |
| `network_model` | `vmxnet3` | مدل کارت شبکه‌ی پیش‌فرض |
| `vlan_id` | خالی | VLAN پیش‌فرض |
| `gateway` | خالی | گیت‌وی پیش‌فرض |
| `ip_prefix` | `24` | prefix پیش‌فرض IP ها |
| `dns_servers` | خالی | DNS همه‌ی VM ها؛ خالی = همان تمپلیت |
| `dns_domain` | خالی | Search domain همه‌ی VM ها |
